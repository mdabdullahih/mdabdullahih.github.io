Security Awareness and Technical Controls in Residential Wireless and IoT Environments: Empirical Analysis, Predictive Modeling, and Mitigation

M.Sc. Thesis · Daffodil International University
Completed Thesis

This thesis investigates residential Wi-Fi and IoT security practices in Bangladesh through empirical analysis, predictive modeling and mitigation-oriented recommendations.

The research explores the relationships among user characteristics, technical confidence, residential network conditions, protective security practices and reported security incidents. It also applies statistical analysis and machine learning classification to examine security practice levels and reported incident status.

The study aims to support practical, user-oriented security improvements through technical controls, awareness and layered residential network protection.

Degree: M.Sc. in Software Engineering (Major in Cybersecurity)
Institution: Daffodil International University
Supervisor: Prof. Dr. A. H. M. Saifullah Sadi
Cybersecurity Residential Wi-Fi IoT Security Machine Learning Predictive Modeling Statistical Analysis

Security Awareness, Technical Confidence, and Protective Behavior in Residential Wi-Fi and IoT Environments: An Empirical Study in Bangladesh

International Conference on Knowledge Integration and Educational Leadership (ICKIEL 2026)
Accepted and Presented

Presented at ICKIEL 2026, held on October 17–19, 2026, at Ahsanullah University of Science and Technology (AUST), Dhaka, Bangladesh.

This study empirically investigates the associations between user characteristics, technical confidence, residential network conditions and protective security behaviors in Bangladesh's residential Wi-Fi and IoT environments. Using a quantitative cross-sectional survey, the study evaluates multivariate relationships through statistical analysis.

The research examines administrative credential management, firmware updates, password complexity, guest-network usage, IoT credential management, Wi-Fi protocol selection, WPS configuration and reported security incidents. It provides empirical insights into the socio-technical dimensions of residential cybersecurity and highlights the need for practical, user-oriented security guidance.

Authors: Md. Abdullah Ibna Harun and Prof. Dr. A. H. M. Saifullah Sadi
Cybersecurity Residential Wi-Fi IoT Security Security Awareness Statistical Analysis

Hybrid Deep Networks with Layer-Wise Tail Optimization and Explainability for Mango Leaf Disease Classification

IEEE 3rd International Conference on Computing, Applications and Systems (COMPAS 2026)
Accepted and Presented

Presented at IEEE COMPAS 2026, held on October 9–10, 2026, at the University of Dhaka, Bangladesh.

The study proposes MangoLeafNet, a gated hybrid deep learning architecture combining MobileNetV2 and DenseNet201 with Grad-CAM explainability to classify eight mango leaf disease categories.

The research uses a self-collected dataset of 2,485 images from Bangladesh, expanded to 12,000 images through preprocessing and augmentation. The proposed model achieved 99.44% accuracy on the self-collected dataset and 91.70% accuracy on the external MangoLeafBD dataset.

Co-authors: Raisa Ferdush, Md. Rakibul Islam Raj, Sanjida Rahman, Sanzida Islam Smriti and Md. Saymon Ahammad.
Deep Learning Computer Vision MobileNetV2 DenseNet201 Grad-CAM Image Classification

Deep Learning-Based Classification of Breast Cancer in Mammogram Images

International Conference on Intelligent Data Analysis and Applications (IDAA 2025)
Accepted and Presented

Accepted and presented at IDAA 2025, held on December 12–13, 2025, at Daffodil International University, Dhaka, Bangladesh (Paper ID: 10285).

The research proposes BreastNet, a hybrid deep learning model for binary classification of mammogram images into benign and malignant categories.

The model achieved 99.50% accuracy on the Mendeley dataset and 95.55% overall accuracy on the external INbreast dataset.

Co-authors: Raisa Ferdush, Mir Mynul Ahasan Mim, Md. Mustak Ahmed, Tahajib Jakir Khan and Md. Saymon Ahammad.
Deep Learning Medical Image Analysis Breast Cancer Classification Computer Vision
